# 证据与规则安全边界实验

这项离线实验检查生产评审服务如何处理引文位置、复核拒绝、材料不足、问题归属、去重与部分报告。它使用开发者预先登记的合成文本及固定候选、复核响应；没有评估商业模型语义质量，没有专家标注，也不是独立盲评。

## 复现

安装锁定依赖后运行：

```sh
npm run evaluate:review-contracts -- --output /tmp/paper-audit-review-controls
```

命令生成 `review-contract-results.json` 与 `.md`。只要一例不符合登记期望，进程退出状态为 1，失败仍保留在两个报告中。默认材料为 [30 个固定用例](../tests/fixtures/review-contract-cases.json)；可用 `--fixture` 指定同一格式的合成材料。工具拒绝把材料标为真实论文或专家数据，不自动发布正式规则。

每例创建独立临时 SQLite 工作空间，调用实际 `createReviewService`，执行候选规范化、原文匹配、逐条复核、问题持久化和报告生成。候选与复核通过内存回调重放，未连接模型服务；报告区分 55 次受控回调与 0 次外部模型调用。单例最多 20 次回调，另设终止时间，结束后关闭服务与数据库并清理临时文件。

每例只启用已登记的 1–4 个现有检查项，保留其规则、权重与版本。所显示分数用来检查软件边界，不能当作完整论文或期刊评审得分。`provisional` 在这里表示该检查子集流程完成，不证明整份论文通过专业评审。

## 预先登记的边界

| 范围 | 固定控制 | 预期行为 |
| --- | --- | --- |
| 原文身份 | 有效连续引文、虚构引文、未知区块、无引用 | 只有当前版本可核对的引文可形成正式批注 |
| 出现位置 | 重复引文、第二处明确偏移、错偏移、字符串偏移、排版标准化 | 重复且无位置时拒绝；明确位置须逐字匹配，不移到第一处 |
| 材料和适用性 | 材料缺失、外部全文不可用、视觉材料不可用、不适用 | 保持不可判定，不扣分、不补满分 |
| 模型复核 | 论证拒绝、非法复核结构、无效等级 | 隔离无效判断，保留原因 |
| 独立问题 | 有效问题、材料请求、复核降级、错误主项、非单一问题、未覆盖的问题 | 只发布逐条通过相应检查的意见；材料请求单列 |
| 去重 | 真正重复、同段不同缺陷、自指关联、无重合证据的关联 | 核对所属检查、缺陷类别和重合证据，不因模型给了关联就删除问题 |
| 部分报告 | 一个有效问题与另一个无效引文并存 | 保留有效意见，但报告必须显示需要补充材料，不能表示全部完成 |

源文本、候选、复核响应和计数、偏移、计分分母、报告状态期望全部保存在材料文件中。位置预期人工登记并独立检查，没有用生产匹配器反向生成答案。报告保存规范化材料 SHA-256、各源区块 SHA-256、各例规则指纹、执行器版本和相关实现文件哈希；改变期望会改变材料指纹。

## 当前结果与发现

2026-10-08 的 [逐项结果](review-contract-results.md) 和 [完整 JSON](review-contract-results.json) 为 30/30 工程边界通过，11/11 正式批注位置有效。固定材料指纹为 `c2e54d90c8145361eafb29d73695e56da6aef2f707586aec945f08f7d4e6864f`。引文策略为 `exact-occurrence@2`，评审执行器为 `4.1.0`。

首次执行同一组材料为 29/30：一个逐条引文失败的部分报告仍显示 `provisional`。修复后只有任务及全部检查完成、计分覆盖合格、所需视觉材料完整可读时才允许该状态；原已通过核验的意见继续保留。材料期望与指纹未因失败而改写。

跨模块检查还发现服务器有时忽略传入偏移、选择重复文字的第一处，或在修订／外部比较保存时丢掉已核验偏移。现在服务器与阅读器共用逐字范围约束：无偏移须唯一；明确偏移必须是非负安全整数并对应实际切片。排版标准化只接受唯一映射，不能修补明确错误的位置。模型证据链可提供相对于检索片段的 `quoteOffset`，服务器核对后换算原文位置。

旧报告、旧任务和解析保持冻结。旧执行器任务不能在新策略下混合重试，需新建评审；界面阅读旧歧义引文时明确提示，不自动生成新位置。新任务及部分工具记录保存引文策略，便于解释当时的校验范围。

## 专业评价仍需独立完成

30 个用例是已知程序边界的工程验收。它们不统计模型发现问题的召回率、科学论证准确率、专家严重性一致率或奖项概率。另有许可清楚的 [真实论文检索](real-paper-validation.md)、[原始 DOCX](docx-validation-results.md) 与 [原始 PDF](pdf-validation-results.md) 检查，分别验证特定材料的解析与定位。

专业校准需要另外取得独立领域专家、预先约定的标注协议、开发集与保留测试集、分歧记录及真实模型运行记录。见 [校准格式](calibration.md)。不能把本实验的固定复核回调或作者在界面点击“确认”当作专家基准。
