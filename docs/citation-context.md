# 正文引用与编号示例

新完成的模型问答使用markdown-body-labels@1。普通正文中连续的[R数字]参与已知/未知来源检查，去重保持首次出现顺序；标题、强调、列表与GFM表格中的正常文字同样可识别。编号存在只说明模型使用了本次来源标签，不证明内容支持结论。

行内、围栏、缩进及未闭合围栏代码，引用块，Markdown链接/图片，链接定义和转义例子不参与统计。不跨格式节点拼接[R数字]，不解释实体编码为编号。原始HTML按保守词法规则排除，未闭合行内标签排除同一词法序列剩余内容；不是HTML5 DOM、安全清理或导航按钮位置图。复杂格式可能不计入，需核对原始正文与来源卡片。现有阅读器导航和原文身份/位置门槛独立保持。

仅有代码示例[R1]时，来源不标为回答已引用，仍提示没有可识别正文编号；正常正文[R1]加代码[R999]不会因该代码示例告警；正常正文[R8]仍提示未知来源。不会删除代码中的编号或更改原始文字/来源。界面清楚说明范围，保存策略供复核；未完成流和本地离线检索没有这项模型完成后的标记。

JSON导出仍paper-audit-chat@2，citationPolicy只在原记录包含时导出，Markdown显示同一策略。旧问答保留原cited、警告和正文，不重新计算、不补造当时策略。新增字段不迁移数据库或改变报告。

三个Node控制和一个真实浏览器控制在3ab3065先登记，原实现分别失败；目标19Node/6浏览器、最终生产构建257Node/72浏览器通过。实际上传合成DOCX，经本机HTTP模型三次SSE回答检查示例/已知/未知、原文与旧消息前缀、JSON/Markdown及手机刷新，未调用外部模型。这些是开发者工程控制，不是专家准确率或模型效果数据。详情和日志指纹见citation-context-validation.json。

使用项目已锁定的Marked依赖，未增加软件包；语法树接口参考官方文档 https://marked.js.org/using_pro#lexer 。
