# 项目与通用对话

更新：2026-11-10。

应用继续使用原来的导航栏、主题、拖动收起交互、管理页和论文证据预览。新增工作区嵌入原 `App.vue`，不再用另一套导航替换主界面。`ResearchApp.vue` 只承载通用对话、项目文件和新产出预览。

## 使用

- 侧栏“新对话”直接交流，无需论文；地址为 `#new`，发送后保存为 `#chat/ID`。
- 侧栏项目分组的加号创建项目文件空间；项目可设置说明，拥有多个对话。项目操作菜单中的“新聊天”开启项目内新对话。项目内各对话共享文件，聊天记录各自保存。
- 独立对话可以移入项目。已有文件一同迁移；重名冲突或正在执行任务时拒绝迁移，避免混写。
- “文件”打开文件列表。可以上传文件、上传文件夹、创建目录、移动或重命名、下载单文件或 ZIP。文件夹上传保留浏览器提供的相对路径；空文件夹不会由浏览器上传。
- 文本产出可手动编辑，并按版本恢复。保存时检查版本，文件已被其他操作更新时不会覆盖。超过预览字符限制的文件只提供下载和读取工具，不允许从截断的预览保存覆盖原文。
- 新对话只显示对话。用户打开文件或智能体生成文件后显示预览；关闭后回到完整对话。论文批注和评审报告作为同一聊天旁边的预览区显示，移除预览中的论文解析与证据工具标签，通过“查看论文”或“查看评审结果”打开。评审完成时自动展开报告。聊天与预览之间的分隔线可拖动调整比例，支持左右和上下布局；比例按账号保存，双击恢复默认，键盘方向键也可调整，手机端单面板预览不显示分隔线。
- 已有论文现在直接打开统一智能体对话：首次打开自动带入当前版本的文件和历史问答，同一论文的各版本共享项目文件空间、各自保留对话。重复打开、刷新、同时打开两个标签页不会重复创建对话。原论文、报告、引用及记录仍保留。
- 移除独立的“历史对话／记录”面板，只保留一个聊天区和输入框。问题详情里的“继续讨论”将上下文带入当前聊天草稿，手机端自动收起预览；不自动发送。
- 评审可以直接在对话中提出，也可通过附件菜单的“评审文件”填入请求。文献库预览的“在对话中评审”同样进入统一对话。模型根据已有文件、历史设置和本轮目标决定读取、联网、匹配模板或追问，不直接跳过这些步骤启动旧流程。
- “文件 → 打开已有论文”也可继续已有论文对话。原文件丢失但保留了提取文本时，明确显示当前只带入文本；正式评审需补充原文件。原记录中的引用可从历史消息入口查看和定位。

## 聊天进展与用时

每轮请求在左上角显示实时用时。工具操作公开说明当前行动、已知发现与下一步，评审引擎逐项更新已核对的观察和建议；文字按需要展开完整段落，不设一两句或120字的展示截断。进展按实际容器宽度重新分段，每段最多4行、段间距24px，优先在完整句子处拆分，全文保留；不展示模型内部推理或核验协议。回答完成后，用时停止并自动收起过程，点击可重新查看；刷新后保留时间和结果。真实服务错误显示错误提示，工具未完成由模型解释；用户主动停止显示普通状态。

## 评审方向、当次标准与模板

用户只说“帮我评审”且历史中没有指定方向时，智能体先列出账号中实际可用的评审标准，同时询问目标期刊或特别关注的方面，并提供通用学术评审选项。已有明确要求时不重复追问；用户说“没有目标期刊，你看着审就行”后，根据稿件类型执行通用评审。没有论文时先请用户提供或选择已有文献。仅提到投稿期刊不自动启动完整评审。

正式评审支持两种规则来源：`review_document.templateId` 引用已有标准，或 `review_document.criteria` 提供本次期刊、通用、自定义标准，两者互斥。本次标准随项目、任务和报告快照保存，不写入模板库；只在用户明确要求保存或编辑可复用模板时调用 `save_template`。当前消息中通过选择器指定的标准仍优先于模型自行传入的标准。

本次标准采用文字评审，检查项区分期刊要求、通用学术检查和用户要求，不生成临时评分权重。期刊来源保存URL或当前对话文件ID、逐字摘录和读取时间；只有与已完成网页/文件读取结果匹配的摘录才标为已读取，搜索摘要和模型自报的核验状态不算。文件来源须属于当前对话/项目并匹配读取版本。缺少来源的期刊检查项只能待核验，不生成确定性缺陷。摘录匹配不代表官方身份认证、指南完整性或期刊内部审稿标准，来源适用性仍需要模型结合原文判断。

未指定报告模板时直接采用默认排版。报告预览及 Markdown/PDF/DOCX 导出包含“本次评审依据”；恢复任务复用任务中冻结的规则与已完成检查，不受模板库或项目当前标准变化影响。

“模板与规范”沿用原编辑器，可逐项编辑。新增通用评审标准；空白标准不再强制附带生态学条目。适用类型包括实证、综述、理论、案例和其他。质量权重合计为 100 时评分；全为 0 时只写意见。

也可以上传 Word/PDF，要求智能体读取要求后创建或修改模板。智能体使用与手动编辑相同的配置存储；更新模板必须携带读取到的版本标识。模板来源可存入来源记录，执行评审时冻结标准版本，不反向修改已有报告。

评审规则和报告排版模板是两类配置。智能体可指定二者；报告排版模板保留已有的六个核心区块，也可增加文字区块和调整顺序。正式评审调用原评审引擎，保留证据核验、覆盖情况、执行状态和同屏证据预览。模板不设论文字数上限；聊天发起或继续的评审不再自动附加15分钟或60次调用预算，旧任务继续时也清除原预算，可随时手动停止。单次网络请求仍保留超时处理，避免连接失效后永久等待。普通聊天分析不会自动当成正式评审报告。

“希望投 SCI 某区”可以作为对话目标。模型根据缺失信息决定是否追问分区口径、年份、学科和目标期刊；检索来源后选择用户指定的已有标准，或形成有来源的当次标准，无需先创建模板。系统没有内置“某区通用官方模板”，无法核验的期刊指标必须说明。

## 联网

联网入口位于新对话标题栏的“联网”按钮：

1. 在原“设置 → 模型服务”连接支持 Chat Completions 的模型，并启用。
2. 启用官方 DeepSeek 连接（`https://api.deepseek.com`）时，自动复用当前账号的模型密钥调用 DeepSeek Search，无需额外填写 Brave 密钥，Flash 也可使用。联网设置显示当前搜索服务。搜索使用独立接口，由 DeepSeek 单独计费，见 [官方搜索说明](https://api-docs.deepseek.com/guides/search/)。
3. 使用其他模型时，可在联网设置填写可选的 Brave Search API Key。每个账号的密钥独立加密保存，读取接口不返回密钥。也可由部署者设置 `BRAVE_SEARCH_API_KEY` 环境变量。启用官方 DeepSeek 时优先使用 DeepSeek；请求失败会提示原因，不自动切换服务。
4. 智能体可以选择公开网页搜索、已知 HTTPS 网页读取、Crossref/DataCite 文献元数据检索。搜索摘要和文献元数据不等于已读取论文全文。展开搜索工具记录可查看搜索词、服务名称与来源链接。

没有启用官方 DeepSeek 连接且未配置 Brave 时，网页搜索明确返回未配置；读取已知公开 HTTPS 链接和文献检索仍可使用，取决于部署服务器能否访问对应服务。网页读取不运行网页脚本、不登录付费网站、不访问本机或内网地址；失败会显示在对话中。搜索结果保留 URL 和检索时间，DeepSeek 结果还保留可用的摘要、正文片段与发布日期。模型应核验来源，不能将搜索结果直接当作已核实的期刊分区。

2026-11-09 已复用本机现有 DeepSeek 连接完成一次真实搜索，返回 6 条结果。可用 `node scripts/check-deepseek-search.mjs --live` 显式重测（产生一次实际搜索请求）；脚本不修改应用数据库、不输出密钥。真实搜索成功不代表已完成期刊分区核验。

## 能力和运行边界

- Web 端操作的是当前账号在服务器中的项目文件空间，不能任意访问用户电脑目录或执行系统命令。文件内容按账号和项目隔离。
- 模型自主选择读取、写入、目录操作、模板编辑、检索、评审和导出工具；一次消息最多执行 32 步。达到上限会保留结果并说明状态，可以继续对话。统一对话显示执行进度及最终回复，目前不逐字流式显示最终答案。原论文问答接口仅保留兼容，当前前端不再调用它。
- 关闭浏览器不会主动取消服务端正在执行的任务。重新打开对话可继续查看状态；可手动停止。服务重启后将未完成任务标为中断，不假称完成。默认开发启动已禁用API自动重启，前端热更新继续可用；如确需后端文件监听，显式设置PAPER_AUDIT_API_WATCH=1，避免在有评审运行时使用。
- 支持 PDF/DOCX 文字提取及文本类文件读写。修改上传文档时，智能体可以生成新的文本草稿并导出 Word/PDF，不会原位保真修改 PDF 或复杂 Word 二进制版式。不支持扫描件 OCR；图像可以预览，但当前智能体读取工具不会声称理解图片内容。
- 单文件最多 25 MB；单批最多 100 个文件、100 MB；单空间最多 2000 项，历史内容合计最多 250 MB。路径只允许项目内相对路径。读取工具分段返回长文，预览最多显示 50 万字符。
- 工具测试使用受控模型响应验证真实 API、存储、解析和评审链路，不代表真实模型的学术判断准确率。实际输出质量取决于配置模型及输入材料。
