# 演示账号与部署

比赛版使用预设账号：登录、退出、记住登录；不提供公开注册、短信或邮件找回。页面采用已确认的蓝色背景、浅蓝品牌区、白色表单和学术线稿，不展示“账号由管理员提供”。

## 创建与重置

在项目目录执行：

```sh
npm run account -- create sample-reviewer
npm run account -- reset sample-reviewer
```

命令生成随机密码并仅在本次输出中展示。用户名不区分大小写；同名创建不会覆盖现有账号。重置会撤销该账号的所有会话。可通过进程环境变量 `ACCOUNT_PASSWORD` 指定10–128字符的密码，勿将真实密码写进仓库、脚本或命令参数。`DATA_DIR` 必须与应用运行的数据目录相同；程序不会自动加载 `.env`。

账号管理只有本机命令，没有远程注册或管理接口，也没有内置默认密码。全新数据库需运行上述创建命令。

## 数据归属

每个账号独占一个工作空间，复用现有 SQLite 的 `workspace_id` 访问隔离。模型配置及加密密钥引用、项目、论文原件、解析、聊天、批注、报告、自定义规则、模板、集合及回收站均随账号。系统内置规则只读共享。

主题、评审设置保存于原有工作空间偏好；面板宽度、阅读位置、最近项目、网格/列表和常用视图也改为账号内按键保存。另一设备登录或刷新后读取服务端值。聊天未发送草稿仍只在当前页面内存中，退出后清空。登录凭据和业务内容不存入 localStorage；其中仅保存用户主动勾选的账号名。

多个设备可以同时登录。后台任务保留原账号归属；退出会卸载工作台并终止前端流式请求，后台已发起的评审可能继续运行。Cookie 变化通过跨标签通知和后端身份请求头检测，避免旧标签将更改写入新账号。流式聊天还定期检查会话撤销或过期。

当前不是多人协同编辑器。同一账号同时编辑同一设置时，以最后成功保存为准；规则/模板继续保留原有版本校验。视图偏好逐键更新，不会用一个设备的整包状态覆盖另一设备的其他键。

## 旧匿名数据

登录成功后直接进入账号自己的工作空间，不显示旧数据迁移页面。新账号从空白空间开始；已有账号继续使用其保存的数据，重新登录不会清空。即使浏览器保留旧 `audit_workspace` Cookie，也不会自动迁入旧内容。旧数据保留，一个空间只能绑定一个账号。

已有业务数据的账号不合并其他空间。如旧 Cookie 已丢失，可由本机管理员核实工作空间归属并新建账号绑定：

```sh
npm run account -- create restored-user EXISTING_WORKSPACE_ID
```

不要将一个人无法确认归属的旧空间绑定给另一个人。此命令对已绑定空间会拒绝执行。

## 记住登录

不勾选：会话 Cookie，无持久化到期属性，服务端最多有效12小时；部分浏览器“恢复上次会话”可能恢复会话 Cookie，因此公用设备应明确点击退出。

勾选：账号名保存在浏览器，随机会话 Cookie 有效30天。密码输入框支持浏览器密码管理器（`autocomplete=current-password`），系统本身不保存或自动回填明文密码。退出立即撤销当前会话，即使已勾选也必须重新登录；账号名可以继续预填。

密码采用独立随机盐的 scrypt 哈希；服务端只存会话令牌的 SHA-256 哈希；Cookie 使用 HttpOnly、SameSite=Strict。错误登录按来源和账号限流，用户名不存在与密码错误使用同一提示。

## 租服务器后

用一台服务器运行应用和持久化数据目录，浏览器统一访问该服务器网址。无需另做浏览器之间的同步系统。分别在两台电脑安装桌面版依然是两个独立本机数据目录；跨电脑使用统一服务器应通过浏览器访问。

配置 HTTPS 反向代理并将 `PUBLIC_ORIGIN` 设为实际完整站点 origin，例如 `https://papers.example.com`。此项启用 Secure Cookie 和精确 Origin 校验；不信任客户端任意转发头。代理应转发 `/api`，保留流式输出并设置合适的上传大小和超时。仅改变 HOST 并不提供 TLS。

该改动只完成演示账号功能，不包含公网资源配额、模型调用费用上限或自定义模型地址的服务器内网访问治理。服务器上线时按实际演示规模配置这些限制；仅向受信任的演示人员发放可配置模型的账号。

备份需同时保留一致的 SQLite 快照、`files/` 原件目录和 `.model-encryption-key`。运行时不能只复制 `copilot.sqlite` 而忽略 WAL；使用 SQLite backup API 或停服后整体备份。会话表包含可撤销的登录状态，恢复到新服务器后可清空 `account_sessions` 要求重新登录。

## 验证

`tests/auth.test.js` 覆盖登录门禁、账号隔离、原件下载、会话寿命/撤销、重启、旧数据认领、来源校验和密码重置。`tests/e2e/auth.spec.js` 覆盖真实登录、记住选项、退出、跨设备、跨标签和响应式布局。现有业务浏览器用例通过 `authenticated-test.js` 创建独立真实测试账号，不使用生产登录旁路。

独立端口运行：

```powershell
$env:E2E_DATA_DIR='test-results/auth-e2e-data'
node node_modules/@playwright/test/cli.js test --config playwright.auth.config.js tests/e2e/auth.spec.js
```

已知原有 Windows 符号链接权限测试失败另行记录，不属于账号功能回归。
