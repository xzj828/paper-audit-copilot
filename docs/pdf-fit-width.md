# PDF适合宽度

工作台论文批注区与文献预览的PDF加载完成后可点击“适合宽度”。按钮以aria-pressed表达状态，画布、位置框容器及连续页面按当前可用宽度等比显示；窗口或面板宽度变化时由CSS跟随，不必反复点缩小。相邻页在桌面各占一列，窄屏保持上下排列，各自保留旋转/裁剪后的纵横比。

模式开启时原缩放比例处显示“适合宽度”，加减缩放停用。再次点击适合宽度可退出并恢复原手动比例；点重置缩放则退出并回到100%。这只是一轮阅读视图：不写入默认缩放偏好，刷新、换版本、换源文件、阅读器重新挂载及预览关闭再开均关闭。Word不提供此开关。

CSS缩放已有画布，不修改原文件、PDF.js内嵌文字、canvas原像素或旋转裁剪规则；不提高渲染分辨率，也不重建图表或表格。位置框仍按当前页原有归一化坐标显示，模式切换后沿用原证据滚动定位；邻页仍不生成证据位置框。正文可在整页适配后显得较小，退出模式后可用原手动缩放查看细节。极宽区域可能将已有位图放大，不能将适配称为更高字形精度。
