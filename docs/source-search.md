# 原文搜索：逐处定位与换行兼容

策略 source-occurrences@1。搜索当前版本的每个已解析区块，按原文顺序逐处显示最多60处匹配，同页重复文字不再只列第一处。点击结果使用该次出现的原始UTF-16偏移和逐字切片，重复数字、手机缩放与刷新后重新搜索均能定位实际位置。界面显示出现位置；位置数字是区块内字符偏移加1，不是页码、字形序号或字节。

多词查询兼容ASCII空格数量及一次LF/CRLF换行差异。兼容命中明确标注“空格 / 换行兼容匹配”，引用仍包含原始换行；不把查询改写后当作原文。字面匹配保留Unicode大小写规则和正则符号转义，同一短语的重叠出现也分别列出。原有逐字引用校验、PDF矩形映射和解析策略不变。

不跨区块、跨页、TAB表格单元格或空行拼接，不删除断词连字符，不补OCR，不重建跨页表格。用户明确输入TAB或空行时只能字面匹配。可检索文字仍不能证明表格行列语义或阅读顺序正确。本轮改变手动原文搜索，BM25问答与科学评审未使用这一新匹配策略；不宣称模型理解更准确。

## 复现

运行 npm run evaluate:source-search -- --output 指定目录；--baseline 使用仍保留且与v11字节一致的literalRange复现原第一处查询行为。该命令写出所有固定预期、实际结果与当前实现指纹，不联网、不调用模型。单独原始材料复跑使用 npm run evaluate:pdf -- --output 指定目录。

后续优先检查真实PDF断词与跨页表格的独立控制，再决定是否需要显式候选核对；不会以宽松拼接制造不存在的原文证据。
