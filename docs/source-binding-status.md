# 对话来源身份状态

页面将保存的检索versionId、parseId与当前版本、解析ID逐项比较。

| 状态 | 页面行为 | 含义 |
| --- | --- | --- |
| matched | 可尝试定位；提示身份一致 | 四个非空字符串ID完整相同 |
| mismatch | 禁用定位；提示重新提问 | 任一有值的保存/当前ID对不符 |
| unavailable | 保留当前原文尝试定位；提示未核验 | 没有已知不符，但至少一个身份缺失或无效 |

身份字符串不修剪后比较；纯空白、非字符串视为缺失。已知不符优先于其他字段缺失。只有ID相同不等于历史文件字节已认证，也不保证引文的出现位置、文字匹配或科学结论正确。现有逐字锚点校验继续负责文字定位，记录不迁移、不补造。

两个调用处覆盖已保存及流式对话。禁用按钮之外，点击处理函数再次拒绝已知不符，防止程序化事件绕过原生禁用。未知记录可由用户尝试核对当前原文，不将未知改称一致。

验证：一项Node内49组有限开发控制与原导出状态比较，另覆盖当前身份部分缺失及原输入不变；两项浏览器分别挂载生产组件和实际从空项目上传合成DOCX、提问、刷新、读取JSON。手机控制包含390px无横向溢出。没有真实用户旧数据迁移，没有专家标注、外部模型调用或独立评测。首次上传测试缺少项目标题就绪等待而未发出上传请求，修正测试等待后通过；失败日志保留。

完整检查为生产构建、242项Node和55项浏览器通过。首轮全量浏览器54/55，旧双版本导出测试未等v2就绪，补充版本切换等待后全部通过，失败日志保持。当前指纹见source-binding-validation.json。旧人工复核、断词和页面切换证明中的App.vue指纹属于保留的v19快照，其余相关实现不变；全量回归覆盖旧流程，未修改旧材料或虚构重测数据。
