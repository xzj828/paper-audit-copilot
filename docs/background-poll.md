# 后台刷新与较新页面状态

工作台有解析或评审运行时，原有定时器每秒尝试GET当前项目。本轮保留该周期与接口，按当前响应式Project对象建立WeakSet：该对象已有进行中的状态读取就跳过本次；请求成功或失败均finally释放。打开其他项目或接受其他操作返回的新对象时，可独立推进，不用一个全局锁等待旧网络请求。

应用轮询结果时，除原来的项目ID、当前版本、导航序号、设置修订和忙碌条件，还必须仍持有请求开始的同一页面对象。完成问答、保存报告或其他操作已替换对象时，旧GET不能覆盖它。接受本次读取后，等待渲染或刷新项目列表再执行滚动/完成提示前继续核对归属；过期的后续动作也停止。

旧实现可在同一请求未返回时发出4条查询；即使项目/版本相同，刚显示的已保存回答仍能被较早GET清空。服务端数据没有被这次GET删除，刷新可恢复。本轮修复已受控复现的页面回退路径；v33有一次等待提示消失超时，不能据此证明其唯一根因或承诺所有提示计时场景已验证。

没有改变服务端写入、解析/评审算法、数据库、问答/报告对象或导出格式，没有自动重发问题或取消服务器工作。过期GET只是忽略页面更新，并不保证取消网络请求或服务商计费。对象内部尚未提交的编辑、其他客户端并发写入及所有其他异步入口不在这次保证范围内。没有新增网络超时：若读取一直未结束，同一快照不会继续叠加请求；重新打开项目取得新对象后可再读，不能称为自动超时恢复。
