# 可复查的证据工具与审查预算

证据工具新增[主张与证据链](claim-evidence.md)，支持原文候选主张、当前版本检索、可选模型关系判断、人工复核记录和冻结报告。以下继续说明参考 DOI、CSV 复算和科学审查预算。

本轮在既有检索、评审和修订流程之外，增加手动触发的参考文献 DOI 核验和 CSV 描述统计复算，并为模型审查增加累计调用与运行时间预算。工具结果保存在具体论文版本内；本轮评审模型尚未消费这些结果，不自动改变科学评分。

## 参考文献 DOI 核验

解析完成后，打开“证据工具 → 核验参考文献”。程序只在明确的 References、Bibliography 或参考文献标题之后提取原文片段，并在附录、致谢、补充材料等标题处停止。PDF 排版、换行、双栏或扫描件可能导致遗漏，快照显示识别范围与截取状态，不能当作完整书目解析。

- 最多提取 100 个片段、100000 字符；最多查询 20 个唯一 DOI，重复 DOI 复用结果并标记对应原条目。
- 只发送识别到的 DOI，使用 Crossref `/works/{doi}` 和 DataCite `/dois/{doi}` 精确查询；不发送论文全文、不猜测 DOI、不调用模型。
- 最多 2 个同时在途的注册机构请求，单请求 8 秒、整批 45 秒，每个响应最多 512 KiB；超限或失败保留未完成状态。
- 状态区分：已取得注册记录、元数据待核对、两源未查到、查询不可用／未完成、未识别 DOI。题名与年份差异提供人工核对线索，出版年与在线年可能不同；不将差异或未查到解释为文献虚假。
- 保存原条目、原文锚点、重复关系、注册元数据、机构 URL、时间、解析身份与文件指纹。点击原条目回到原文，可下载受空间与版本访问保护的 JSON。

只核对注册元数据；本轮没有验证引用是否支持正文、取得文献全文或核查撤稿。接口依据 [Crossref 官方文档](https://www.crossref.org/documentation/retrieve-metadata/rest-api/) 和 [DataCite 单 DOI 查询文档](https://support.datacite.org/docs/api-get-doi)。

## CSV 描述统计复算

在“证据工具”上传论文对应的 UTF-8 CSV，预览前五条，选择数值列，可选分组列及 ID 列。列按序号映射，避免同名标题造成歧义。可输入论文的全表均值和绝对容差，并选择当前版本段落、粘贴逐字原文作为比较依据。

- 文件最多 2 MiB、20000 条数据记录、100 列、100 个分组。支持引号内逗号、换行、双引号转义及 BOM；编码、引号结构或各行列数错误会明确拒绝，不悄悄截取。
- 全表和分组统计包括记录数、有效值、缺失值、非法值、非加权算术均值、样本标准差、最小和最大值。使用缩放 Welford 计算，标准差分母为 n−1；有效值不足或超出有限数值范围显示不可计算。
- 空白视为缺失；NA、文本、公式、Infinity、十六进制及非有限数值记为非法并排除。工具不运行单元格公式或任意代码。
- ID 重复仅是重复记录提示，重复测量可能合理，不自动删行或判断伪重复。均值超出容差仅表示数值差异，需核对数据版本、单位、权重、筛选和舍入，不判断造假、显著性或因果。
- CSV 发送到当前部署服务，在请求内计算，不发给模型；全文不写入项目。每个版本最多保存 10 份快照，包含 CSV SHA-256、列映射、算法版本、统计结果、原文身份和比较条件。重现精确计算需要团队保存原 CSV。

工具是描述统计入口，尚不支持显著性检验、自动选择统计模型、加权均值、任意过滤和原始数据独立性验收。

## 模型审查预算

“审查预算（可选）”设置最多调用次数（1–200）和累计运行分钟数（1–120），可留空不限。预算属于整次科学审查任务；成功、失败、输出额度不足后的自动重试均计入调用。实际运行时长包括模型等待和页面渲染，暂停等待用户的时间排除，与累计请求耗时分开记录。

达到限额进入 `budget_paused`，保留已完成模块、页图阅读记录和部分报告，显示覆盖缺口。提高预算后“提高预算并继续”沿用同一任务、原规则和模型，只执行尚未完成的检查；视觉不足时按原复核策略处理。旧报告冻结，预算变更记录另存。手动取消仍单独标为取消。

此功能控制工作量和运行时长，不计算费用。服务商缺少用量返回时不能把未记录 token 当作零费用；实际费用仍以服务商账单为准。问答和修订复查尚未纳入此预算。

## 报告与验证

“保存工具快照到报告”生成新的解析报告，并打开本次新报告；科学评审生成报告时也复制当时最新的工具快照。报告正文可展开冻结的证据工具记录，导出 Markdown/PDF/DOCX 包含独立工具附录和审查预算溯源。导出是可读摘要，完整结构化内容见各工具 JSON；后续核验、复算和作者问题状态更新不会改写旧报告。

自动测试使用合成论文、已知统计量的 CSV 和受控注册机构／模型响应，覆盖边界、网络失败、预算恢复、精确版本和空间隔离、原文点击、真实浏览器下载及移动布局。受控测试证明软件行为；真实商业模型质量、领域专家金标准和盲评对照仍需补齐。

冲击高水平奖项的下一步建议：先用获准使用的真实论文和数据开展小规模专家试标，再建立保留测试集；比较基线与新版的漏检、误报、原文定位和修订建议可执行性，公开失败案例与成本。随后再评估主张证据链、跨文献混合检索和受约束工具调用，不用新增技术名词替代效果证据。
