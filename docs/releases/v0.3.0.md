# 星笺 · 学术审稿 agent v0.3.0

本版本将 v0.2.0 以来的研究工作台更新带到 Windows 桌面版，包含对话式评审、文献库、原文批注、证据工具和报告导出。首次安装可直接在应用内创建本机账号。

## 主要更新

- **对话与研究项目**：独立聊天、项目共享文件、附件卡片、文件夹上传、产出预览和文本历史版本；聊天中可选择模型、指定评审方向并查看任务进度。
- **文献库与评审入口**：批量导入 PDF/DOCX，支持集合、搜索、标记、预览和下载；按文件内容去重。每次显式发起新的文献评审创建独立项目，保留已有对话与评审记录。
- **原文和证据**：PDF 原页、DOCX 结构预览、定位批注与引用、全文检索、修订稿比较，以及 DOI、主张证据和描述统计工具。
- **评审与报告**：通用、期刊或自定义依据，记录本次评审范围和证据；正式报告可导出 Markdown、DOCX 和 PDF。
- **桌面首次使用**：创建账号、确认密码并自动登录；已有匿名工作空间可以在首次创建账号时选取并绑定，原始数据保留。Web 部署仍由管理员创建账号。
- **发布修复**：修复数据存放在隐藏父目录时原稿下载返回 404；安装包仅收录运行所需目录；开发服务器忽略打包输出，避免 Windows 文件锁导致退出。

## 下载与首次使用

1. Windows x64 下载 `PaperAuditCopilot-Setup-0.3.0.exe` 并安装，无需另外安装 Node.js。
2. 首次启动创建账号，密码为 10–128 个字符；如果检测到旧工作空间，可选择接续原有数据。
3. 在“设置 → 模型服务”配置自己的模型连接，然后上传论文或从文献库发起评审。

安装包尚未代码签名，Windows 可能显示未知发布者。请从本仓库 Releases 下载，并核对同名 `.sha256` 文件。

```powershell
Get-FileHash -Algorithm SHA256 -LiteralPath 'PaperAuditCopilot-Setup-0.3.0.exe'
```

SHA-256：`12f062ce0833cf8c18de35e6f4b72af512597c5a37c598a80be47be2ede65a29`

`RELEASES` 和 `paper_audit_copilot-0.3.0-full.nupkg` 一并提供给自动更新服务，手动安装只需下载 `.exe`。

## 数据与升级

- 论文、对话、报告、数据库和模型配置保存在本机用户数据目录。升级前请退出应用并备份整个数据目录，包含原件和模型加密主密钥。
- 使用 AI 评审或联网工具时，相关文本、页面或请求会发送到你配置的服务商。请结合稿件授权和服务商数据政策使用。
- 保持原应用标识与更新仓库，升级不主动删除用户数据。首次迁入只绑定选中的旧工作空间；其他工作空间保留，已有账号不会被覆盖。

## 本次验证与边界

- TypeScript 检查与 Vite 生产构建通过。
- Node 单元及 HTTP API 测试：365 通过、0 失败、1 跳过。跳过项为当前 Windows 进程没有权限创建符号链接的目录边界测试，其余缓存完整性检查正常执行。
- 登录、账号隔离、跨设备/跨标签、响应式登录、批量文献导入和文献评审入口的 7 项浏览器测试通过（6 项主轮通过，1 项更新旧入口断言后复测通过）。
- 开发态和打包后的 Electron 程序均完成账号创建、密码确认、自动登录、PDF 上传解析、原稿字节核对、文献对话、重启持久化和后台关闭检查。打包程序另通过旧工作空间迁入检查。
- 安装器内的更新包与发布的 `.nupkg` 一致；其 `app.asar` 与完成启动检查的程序逐字节一致。检查确认安装包没有收录本机数据库、密钥、测试输出或项目文档目录。
