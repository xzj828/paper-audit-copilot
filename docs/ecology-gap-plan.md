# 生态学首版：剩余缺口及补齐顺序

更新：2026-09-26。当前范围限定为生态学实证研究，不把扩展到其他学科作为近期任务。生态学综述、Meta分析、方法论文仍需各自的规则与验证，不能直接冒充已支持。

## 已有能力与验收层级

- 已实现：上传解析、分项评审、精确引文校验、第二轮模型复核、任务重试、版本化报告。
- 已接入试运行：固定提交的 Nature reviewer/statistics 部分规则适配、PDF 页面与图表视觉输入、Crossref/DataCite 检索与摘要比较、语义版本复核、可编辑规则与报告模板、PDF/DOCX 导出。
- 本轮新增真实 DeepSeek 调用实验与接口修复，实验材料是自制生态学文本和图表；这不等于真实论文或专家准确性验收。
- Nature 采用规则映射和受控流程，不直接运行原版 Skill；八条适配规则也不代表上游全部能力移植完毕。

后续修复进展：0.3版已经实现下表中的逐条问题、主项归属、证据级去重、材料请求分离和修复路径字段，并进入回归与同样例实测。见 [逐条问题修复记录](atomic-review-verification.md)。下表仍保留最初发现与验收目标；其余能力不因这一修复自动视为完成。

## 先补影响判断可信度的缺口

| 顺序 | 工作 | 具体实现 | 验收条件 |
|---|---|---|---|
| P0 | 生态学质量回归集 | 保留独立样地/土样子样、伪重复、空间相关、重复测量、储量与通量、相关与因果、机制外推、遥感验证泄漏等成对控制样例；引入获准使用的真实论文和专家盲标 | 报告漏检、错误指控、证据定位、严重性、可执行性；分研究类型展示，不以模型自评替代专家基准 |
| P0 | 问题拆分与主项归属 | 本次实测中 E03 把伪重复、储量/通量、机制外推合并为一条，导致后续专项被整体标为重复；需将结果改为独立问题列表，约束各维度责任，并按“同一主张+同一缺陷+同一证据”去重 | 一个问题只扣一次，但三个独立问题不能被一个粗粒度 duplicateOf 全部吞掉；无效或尚未存在的主问题编号保持拒收 |
| P0 | 缺材料与真实缺陷分离 | 在结果 Schema 增加明确问题类型和修复路径；缺项只形成材料请求，不能仅因模型称其为 explicit 就扣科学性分 | 同一资料“尚未提供”和“明确错误”成对输入时，前者不形成已证实科学缺陷；E08 数据获取问题与研究有效性分开 |
| P0 | 核心结论与修复性判断 | 保存核心主张、设计证据、影响范围、重分析/补材料/新采样等修复路径，再生成总体建议 | 不把严重伪重复仅按加权平均掩盖，也不因报告缺项自动拒稿；高风险结论保留人工复核 |
| P1 | 显式语义结构 | 从 Paper IR 构建“研究问题—假设—实验单位—采样层级—分析—结果—结论”的持久化对象，带原文锚点 | 一项主张能追溯到方法与结果；多个模块复用同一对象，防止各自理解层级和重复扣分 |
| P1 | 外部文献与创新性 | 在现有元数据/摘要检索之上实现检索式、近邻研究筛选、合法可访问全文和逐条主张比较；中文来源按实际权限接入 | 保存查询、日期、来源、访问层级及精确引文；检索不到不推定不存在，摘要不足不生成完整创新性得分 |
| P1 | 文档视觉与覆盖率 | 为扫描PDF补OCR与置信度；完善多面板图、跨页表和公式结构；按需分批渲染长文，DOCX 图表建立稳定定位 | 每条观察能回到源页/区域；不可读区域明确列出，不把部分页面成功误报为全文成功 |
| P1 | N/A 与评分 | 独立区分不适用、缺材料、解析失败、证据不足，并按设计文档处理适用权重 | 只有真正不适用项可调整分母；无法判断项不能通过重归一化“补出”完整分数 |
| P2 | 规则适配与审计完善 | 逐条扩展 reader/search/data/ref-verifier 的来源映射、条件、例外与边界例；完善模板字段及报告验收 | 每条新增能力有来源与测试；历史规则、报告和检索快照保持不变 |

## 下一批交付应当是什么

逐条问题、缺项分类及修复路径已接入0.3版。下一批重点是扩展生态学回归集、真实论文专家校准及总体修复性判断，再扩展全文检索和复杂解析。已有语义复审、模板编辑和报告导出进入回归维护；暂不以重复增加界面功能代替准确性验证。

真实论文验证需要获准使用的论文与独立领域专家标注。当前仓库没有可据以计算专家准确率的数据；不得用两个人工构造的文本样例外推全领域性能，也不得将第二次同模型调用称为专家确认。
