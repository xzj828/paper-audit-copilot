# 6 分钟普通话演示脚本

录制要求：MP4、1920×1080 或更高分辨率、普通话讲解；总时长控制在 5–8 分钟。以下是录制提纲，不是已录制视频。演示用团队自有或许可公开的论文，遮蔽 API Key 与个人数据。

| 时间        | 画面与操作                                                                       | 讲解重点                                                                                                                       |
| ----------- | -------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| 00:00–00:40 | 浏览器打开 Web 工作台，展示空首页和项目创建                                      | “这是学术审稿 Copilot。我们针对论文阅读、评审证据和修订记录分散的问题，构建可追溯的研究工作台。”                               |
| 00:40–01:20 | 上传 PDF/DOCX，显示真实解析进度、原文页和解析限制                                | “文件经过去重和后台解析。PDF 保留页与文字坐标，Word 保留段落、表格行列、合并与有限格式。无法提取的图像不会被当成已读取文本。”  |
| 01:20–02:00 | 询问论文后部的具体方法，展示检索范围、流式回答和证据卡片，点击定位               | “从全部已解析文本中检索，将有限片段送给模型，回答引用与原文可直接对应。没有命中时不调用模型，也不断言论文没有证据。”           |
| 02:00–02:50 | 选择一个原文候选主张，建立证据链，展示模型关系与逐字原文，点击定位并追加人工复核 | “模型判断支持、矛盾、上下文或不明确。服务器核对引文，人再核对论证；记录会冻结到报告，模型判断不自动成为专业结论。”             |
| 02:50–03:30 | 查看参考 DOI 元数据；上传已知数据 CSV，展示均值差异、点击原文并下载记录          | “数据由确定性工具复算，元数据从注册机构取得。差异需要核对，不自动判定造假。此演示 CSV 是合成控制样例。”                        |
| 03:30–04:10 | 配置已启用模型，设调用预算，启动科学评审；展示已完成问题与预算暂停，提高后续跑   | “评审采用显式检查与独立复核。预算耗尽保留部分结果和覆盖缺口，继续同一任务；旧报告保持冻结。”                                   |

| 04:50–05:30 | 打开报告、查看覆盖率并导出 Markdown/PDF/DOCX；切换手机宽度                       | “报告保存版本、规则、证据和覆盖范围。论文、对话和问题可以联动定位，也支持窄屏阅读。”                                           |
| 05:30–06:00 | 展示真实 Git 提交、测试结果、检索评测逐项结果和能力边界                          | “评测可离线复现，并保留已知漏检。开发回归不等于专家准确率；真实领域校准仍待完成。目前不支持扫描件 OCR，也不宣称替代同行评审。” |

建议提前准备一个已完成的真实模型任务用于展示结果，同时现场启动一个新任务展示调用和进度。不得把预先保存的结果描述为刚刚产生，也不要用加速画面伪称实时速度。

00:40–01:20 的解析画面可替换为逐页体检：先展示有文字／无文字／缺坐标的页数，再筛选并跳到待核对原页，下载身份明确的 JSON；报告展示生成时体检附录。解释“有文字和坐标不代表图表已经理解，文字较少也不能认定扫描件”。若演示三页手工控制，明确第3页是矢量色块，不是实际扫描论文；当前原始PLOS20页案例新增第4页并列文字区提示，原页可见Table 1；多次跨区不等同于抽取错误，其他页未触发也不代表完整排版解析。替换已有画面，保持原总时长。

正式演示不需要让评委等待全部检查结束。长耗时评审的等待可通过画面切换说明，但保证关键流程可核查。录制前核对团队信息、比赛编号、模型服务费用、论文许可和最终文件时长。

公开案例可使用 `tests/fixtures/published-docx/beule-2021-s1-table.docx`：PLOS 2021 年论文的原始 S1 Table，保留作者、DOI 和 CC BY 4.0 署名。上传后展示 R²、上标 a/b、加粗与 6 行 6 列表格，查询 `soil type R2 F` 并点击原文的 15.021；随后切到手机宽度展示表格横向滚动。它验证上传、表格预览和定位，不代表对 PERMANOVA 方法作出专业评判；可以替换上述 00:40–02:00 的一部分操作，保持总时长。

也可用 `tests/fixtures/published-pdf/beule-2021.pdf` 的 20 页原始文件替换上述上传与问答：查询 `S1 Table PERMANOVA results`，点击第 16 页的来源，展示后部材料对应的文字块框，再用原文搜索 `S1 Table.` 定位实际命中。缩放时位置框仍跟随页面；框可能包含相邻字，双栏与表格关系仍需人工核对。原文件、作者及 CC BY 4.0 署名保持原样。不要把本地确定性检索说明为模型评审或专家准确率。

若突出引用可靠性，可将 02:00–02:50 的部分画面替换为重复引文控制：明确标为“合成控制”，展示缺少出现位置时拒绝、保存第二处偏移后在手机刷新仍定位到第二处。旧 DOCX 记录显示“引文出现多次”提示；部分评审有有效意见但另一引文失败时，报告仍显示需要补充材料。实际控制截图及协议见 claim-evidence.md。最后展示 review-contract-results.md 的 30 个固定规则用例、来源指纹与零外部调用，说明它验证工程边界，不能称为专家准确率。该段替换已有操作，避免扩展总时长。

若展示跨语言检索，可替换 01:20–02:00 的部分画面，使用明确标为“合成控制”的英文 DOCX 查询“光合作用”或“生境破碎化”，展示映射说明、英文原句、原文定位与导出字段。对照只含 DNA fragmentation 的近似词控制，说明完整术语边界。用 retrieval-terminology.md 展示原38例和另外24例的全部结果及开发者标签；不要称为通用语义检索或专家准确率，也不要把这一自编控制称为真实研究论文。

可在原解析画面展示并列区控制：明确标为开发者手写两页PDF，第一页按栏抽取、第二页逐行交替，切换次数分别1与9；筛选待核对页后点击原页，展示原文未重排和JSON保存计数。若使用原始论文，展示第4页Table 1而不称为双栏错误检测。详见pdf-layout.md，替换已有画面，保持总时长。

可用开发者手写PDF替换原有搜索画面：搜 Repeated sample 312，分别点击左上和右下两处；再搜 Line one of a quoted passage Line two of a quoted passage，展示兼容标签及两个原文文字框，切到390px并缩放。明确为开发者控制，不称为真实论文。搜索不改写原始文字、不跨表格单元格或页拼接，替换已有画面以保持总时长。

若突出独立复核准备，可替换已有报告画面：下载所选冻结报告的人工复核材料，说明隐藏哪些结构化字段；导入明确标为开发者软件控制的两份记录，显示分歧与双方无法判断，下载完整清单并切到手机。不得将控制代号当作真实专家，也不得将“选择一致”说成准确率。没有全文goldIssues，本功能不统计漏检召回。替换原片段以保持视频总时长。

若展示断词检索，可替换已有原文搜索镜头：上传上述原始PDF，输入environmental，指出默认搜索只能找到完整拼写；勾选“查找 PDF 换行断词候选”，点击第1页environ-换行mental，展示两行位置框和阅读器人工核对提示。说明原文没有被改写，真正复合词也可能进入候选；不能说模型因此理解词义。替换片段以保持总时长，不另外增加视频时长。

可替换原文阅读镜头：用上述原始PDF搜索第4页Table 1，开启“相邻页对照”，选择下一页并最大化预览，展示两张原页和各自页码，再关闭恢复连续阅读。说明这张Table 1未跨页，功能用于人工查看邻页上下文；不称为表格自动重建。手机上下排列、位置框只属于当前页，替换已有镜头以保持总时长。
