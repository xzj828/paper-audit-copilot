# 回答正文中的原文引用

保存及生成中回答里的[R1]等编号现在可以直接定位本条回答提供的真实来源，复用证据卡片的原文导航和摘要聚焦。编号必须在该回答来源集合中唯一存在，不允许编号发明页码、文件或路径。未知/重复来源ID、不完整编号保持文字；每条最多200个正文按钮，超过后仍可使用完整证据卡片。原生按钮支持键盘与手机。

材料身份和原文出现位置独立检查。已知身份不符、文字/偏移/双方物理页不符或重复歧义时禁用，点击事件还会重新读取当前材料；程序化事件不绕过。缺少旧身份或解析时按既有规则保留人工尝试，不表示来源已经核验。编号可点不代表回答结论正确。

Markdown先经DOMPurify清理并移除资料中的button，随后只在普通HTML文本节点创建自己的按钮；已有链接、代码、kbd/samp、引用块、SVG/MathML等非HTML节点不改。资料HTML属性不能提供导航目标，不执行图像事件。引用文字、已保存消息、原文解析及JSON/Markdown导出不改；生成中来源可点击，但尚未完成的回答仍受原有保存/停止规则控制。

两项实现前登记控制在旧界面失败。最终三项新浏览器：生产组件验证唯一来源、键盘、HTML边界、未知/重复ID、原文与身份门槛、不完整编号和200上限；实际DOCX上传验证手机、刷新、原文定位和完整版本不变；真实本机SSE验证半个编号无按钮、完整编号可定位且停止不保存。首次目标8项回归、最终3项新流程通过，完整构建250项Node与67项浏览器通过。有限软件控制不是专家准确率，未调用外部付费模型。日志与实现指纹见inline-citations-validation.json。
