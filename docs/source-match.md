# 证据的当前原文状态

页面与导出通过同一shared/source-match.js检查当前解析原文，使用原quoteRange策略；不会规范化引文或重写历史记录。身份状态独立显示，文字状态不能替代材料身份检查。

| sourceMatch | 含义与页面行为 |
| --- | --- |
| exact_match | 逐字引用及唯一/明确出现位置有效；可定位，不代表结论正确 |
| ambiguous | 原文重复且没有偏移，含重叠重复；停用定位 |
| not_found | 文字、偏移、区块或双方记录的物理页不匹配；停用定位 |
| identity_mismatch | 有解析且已保存版本/解析身份已知不符；停用定位 |
| unavailable | 没有当前解析，不能检查；身份没有不符时保留人工尝试定位 |

身份不符即使同时缺少解析，也继续禁用定位。缺失身份时逐字检查只能证明当前文本，不能确认生成时材料。物理页只在双方都有记录时比较；DOCX不虚构Word页码。负数、分数、字符串、null或非安全整数偏移拒绝；空白与LF按原样保留，after字符串按既有规则接入。点击事件再次读取当前解析状态，避免单靠原生disabled；没有新增科学正确性分数。

两项Node中18个固定开发控制覆盖重复、重叠、明确第二处、错误页、缺失页、大小写/LF、区块缺失、空白、身份与after，以及导出同状态、原输入不变。两项新浏览器分别挂载生产组件和真实上传合成DOCX；另复跑实际重复DOCX控制，先拒绝无位置旧锚点，再按明确偏移验证第二处高亮。旧锚点由测试构造，不是用户数据迁移或专家标注。
