# 显式逐字短语检索

在“询问 Copilot”里使用英文双引号或中文“”指定必须保留的原文：

- `glacier data "312 independent samples"`：同一来源片段必须包含`312 independent samples`；glacier/data只参与关键词排序。
- `resolution “small or elongated”`：可在已登记Lawrence2021原始PDF里核对第17物理页。材料、署名、CC BY 4.0及原文件指纹见[fourth-pdf.md](fourth-pdf.md)。
- `glacier data "absent catalyst"`：在本轮合成DOCX控制中没有匹配来源，明确不调用模型；不能外推其他材料也没有此词。

## 条件与范围

所有加引号的短语须同时出现于同一来源片段，标题命中不能代替正文。逐字比较当前解析文字，区分大小写、空格、换行；不做词序重排、术语翻译、PDF断词合并、排版归一化或正则匹配。纯符号也支持。每项1至100 UTF-16字符，最多8对引号，重复项合并；不支持嵌套/转义。空白、超长、过多、未闭合或混用引号会报错，本次问题不保存，不静默放宽。

来源是原有最多1000字符/重叠120字符片段，不是全文逻辑段落。多个短语分别位于不同页、不同区块或不同片段时可能没有候选，即使各短语分别存在。限定区块选项继续生效，不向其他区块回退。片段预算、来源去重和最多8条来源/12000字符上下文仍限制实际提供数量。候选数先于预算和去重；它与实际提供来源数可能不同，不能称为总出现次数。

未加引号的查询继续沿用原BM25；显式条件采用exact-chunk-phrases@1。追问沿用用户主题时保留其中条件，普通新问题不继承旧条件。已选意见不能用优先级绕过显式短语。无来源时本机检索说明不足；已配置模型也不调用provider。匹配成功只说明提供片段包含字面文字，不保证回答由片段支持，历史对话仍遵循既有模型历史策略。

## 保存与导出

回答的检索说明展示短语、同一片段要求、候选/当前范围片段数及实际提供数。JSON和Markdown导出保留phraseFilter的policy、phrases、matchingChunks。它绑定既有版本/解析身份，保留原始来源偏移；不改原解析或冻结报告。老消息没有该字段时按原样显示/导出，不假造当时的条件。文字在Vue中转义，Markdown条件通过已有安全转义输出。

## 实际验证

初始4883073登记6Node/1浏览器控制，4fd8873在生产改动前修正浏览器段落隔离与provider观测方式。旧实现6Node失败；浏览器缺少短语仍返回6/6片段并请求本机provider，基线追踪保留。b611137实现后，补充真实原PDF等控制，最终23Node/3目标浏览器及完整构建284Node/102浏览器通过。

覆盖：连续文字/词序/标题反控制、符号、多个短语同片段、大小写、长度/数量/语法、片段边界、预算、限定区块、追问、已选意见、JSON/Markdown及旧记录不回写。原始Lawrence PDF保持22页及固定SHA-256，实际命中第17页，全部返回锚点逐字有效；人工加入缺失标记的负控制明确属于开发者软件检查。实际上传合成DOCX、手机刷新、下载JSON及无效请求前后版本一致均通过；新浏览器流程负问题0次/正问题1次受控本机provider，外部模型请求0。

不是专家准确率、未见材料性能、全文漏检率或科学支持评价，也没有OCR或跨页关系重建。当前技术PDF保留v45历史版本；本轮计数和边界以本说明、验证JSON和交付核对为准。
