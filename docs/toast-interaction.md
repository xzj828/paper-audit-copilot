# 提示条与下方操作

提示条显示时，正文不再拦截指针，用户可直接点击其下方操作；右侧“关闭提示”继续响应点击。消息、role=status、原5秒自动关闭及手动关闭逻辑保留。这仅改变命中测试，不改变报告、数据复算、文档解析或模型行为。

## 复现与验证

v48实际失败追踪中，提示条拦截“保存工具快照到报告”的点击。本轮先复现同类问题：上传DOCX、准备两条CSV数值2/4，触发不支持文件扩展名的真实提示；使用浏览器软件时钟暂停其自动消失，将复算按钮滚动到提示实际覆盖的位置，测量交集并直接发送屏幕坐标点击。不强制点击，不注入布局样式，不用DOM调用替代鼠标事件。

旧实现的实测命中元素是toast-message，70px×38px重叠处点击后0条复算记录。修复只加两条CSS：提示正文pointer-events:none，关闭按钮pointer-events:auto。新控制要求交集宽高均大于8px、屏幕点命中实际按钮；创建仅1条均值3快照，原解析、报告与消息保持；提示仍在，关闭按钮可正常点击且不新增记录。命中点观测随测试结果附件保留。

早期控制有两次准备修正，历史如实保留：API准备后应明确选择解析页；普通locator.click可能自动滚动，改为测量后的原始鼠标坐标。最初准备失败和后来locator通过不能算作产品修复前后的有效证据；确认遮挡的日志/追踪独立保留。注册提交fd507a4/5435323/f2225c0，生产修复9a5bad0。
