# 第九届传智杯 AI WEB 参赛说明

核对日期：2026-10-07。本文对照参赛者提供的官方赛道长截图，以及[东莞理工学院发布的第九届赛事通知](https://cs.dgut.edu.cn/info/1034/19118.htm)。[官方赛道入口](https://www.boxuegu.com/matchTrack/detail/?id=10037)为动态页面，最终以赛事个人中心显示的规则和提交入口为准。院校选拔截止日期不能当成全国省赛截止日期。

## 作品与场景

学术审稿 Copilot 是面向生态学实证论文的 AI Web 工作台。目标用户是需要在投稿前梳理论文证据、核对研究设计、跟踪修订问题的学生和研究者。核心交互是：上传真实 PDF/DOCX → 提问并查看原文证据 → 按项评审和复核 → 记录问题与修复条件 → 比较新版本 → 导出可追溯报告。

正式参赛演示使用浏览器中的 Vue 3 Web 应用。Electron 安装包是附加交付形式。产品首次打开为空工作空间，不预置假论文或假评审成绩。

AI 子项中的 RAG 采用可复现的词法检索：1000 字符片段、120 字符重叠、BM25 排序、有限的中英术语扩展，最多 8 个片段及 12000 字符上下文。不使用向量数据库，不称为语义向量检索。现有评审是显式规则工作流，不冒充自主决策 Agent；尚无 MCP/Function Calling 协议接入。展示这些实际边界比在文档中堆叠技术名称更便于核查。

## 本轮问答改进

过去模型问答只发送前 24000 字符，论文后部无法参与上下文。本轮改为在当前版本全部已解析文本中分块检索，再发送相关片段。中文问句先分词，支持少量科研词汇的中英扩展；选中的批注只有在本版原文中存在时才优先检索。

回答引用本次证据编号 `[R1]` 等。证据卡片来自服务器保存的原文切片，点击跳转到对应页或段落；模型不能生成导航目标。服务端检查引用编号是否属于本次提供的片段，未知编号显示警告。该检查证明编号对应关系，不证明模型结论正确。

“概括论文”等一般问题使用跨全文的均匀抽样并标明范围。没有命中时直接显示证据不足，不调用模型、不发送无关首页文本。问答的片段、解析 ID、版本 ID、检索策略和范围说明与消息一起保存；不改写历史报告，不搜索其他项目。

后续迭代支持明确的简短追问，沿用当前版本近期用户问题中的主题并重新检索原文；不把模型的历史回答当成原文来源。可从项目菜单导出当前版本 Markdown/JSON 对话研究记录，包含完整证据、范围、文件指纹和引用警告，便于同伴复核。详见 `docs/conversation-notes.md`。

## 证据工具与效率控制

新工作区支持从明确参考文献区段识别 DOI，精确查询 Crossref/DataCite 注册元数据并显示差异、来源和未完成范围；支持上传 CSV，确定性复算样本数、均值、样本标准差和分组结果，再与人工输入的论文均值及逐字引用比较。科学审查预算按整次任务累计调用与运行时间，耗尽后保存部分报告并允许提高预算继续。独立工具结果、预算变更和原文身份保留到报告快照，暂不参与科学评分。详见 `docs/evidence-tools.md`。

这些功能可展示实际工具计算、失败恢复和可追溯结果。本轮未接入 MCP 或 Function Calling，不能将手动证据工具称为自主 Agent；没有用自动测试成绩代替专家质量评测。

## 复现与环境

1. 安装 Node.js 24.12 或更新版本，运行 `npm ci`。
2. 开发：`npm run dev`，浏览器访问 `http://127.0.0.1:5173`。
3. 生产：`npm run build` 后 `npm start`，访问 `http://127.0.0.1:3001`。
4. 模型配置通过“设置 → 模型服务 → 管理模型”输入兼容服务地址、模型 ID 和密钥。密钥在服务端加密保存，不放入 Git 或前端构建。未配置模型仍可检索原文。
5. 环境模板为 `.env.example`；依赖由 `package-lock.json` 固定。默认本机监听和匿名空间，数据保存在 `DATA_DIR`。
6. 安装测试浏览器：`npx playwright install chromium`；执行 `npm run check`。Linux CI 可用 `npx playwright install --with-deps chromium`。

正式评审使用真实模型服务可能计费。本文及本轮测试不包含用户私有论文、真实访问密钥或商业服务模拟结果的准确率声明。

- 技术文档：PDF，不超过 30 页，涵盖项目概述、需求、系统架构、AI 方案、实现、测试部署和展望。随仓库提供同内容可编辑说明。
- 演示视频：5–8 分钟，MP4，至少 1080p，普通话讲解。按 `docs/demo-script.md` 演示完整功能，明确区分受控样例与真实模型。讲解视频仍需团队录制并最终核对。
- 在线演示：可选加分项。默认本机 Web 服务尚不是公网部署；公开部署需实现服务级访问和容量管理，再提供真实 URL 与评审账户。不得把本机地址当作公网演示链接。
- 本轮 AI 开发记录：`docs/ai-development-log.md` 记录真实需求、发现的问题、改动及测试。历史对话没有原始资料的部分不补写为“真实 Prompt”。
