# 仅检索已定位区块

默认在当前版本全部已解析文本中检索。要限定范围，先通过原文搜索/证据定位DOCX区块，或停留在PDF目标物理页，再勾选“仅检索已定位区块”。一次只选择一个已解析区块，PDF对应一页；DOCX表格可为一个区块，不是Word页码。没有有效位置、正在生成或已关联批注上下文时不可勾选；询问批注先恢复全文。切换项目、版本、解析或位置会取消范围，刷新也取消；它不是持久偏好。问答文字草稿仍按各项目/版本保留。

请求携带当前解析ID和区块ID。服务器在模型/SSE之前确认格式、解析相同且区块唯一；错误范围及批注上下文冲突拒绝，问题不保存，不自动改为全文。检索仍使用bm25-lexical@3，在原切片内筛选所选区块再排名或均匀抽样，不改变原文字与偏移；仍受8个片段/12000字符预算限制。未命中不借其他页，不调用模型，也不代表全文没有相关内容。

界面和导出记录requestedScope（single-section@1、parseId、elementId、section、documentChunks）。totalChunks是限定区块片段数；documentChunks是全文片段数，不能把限定分母当作全文覆盖。JSON继续paper-audit-chat@2，Markdown显示限定区块；无此字段的历史记录不补造。白名单不导出未知字段。

限定模型请求不包含历史问答或其他区块的批注材料；明确短追问仍只沿用近期用户问题主题，并标明本次检索主题。模型完成后再次检查解析身份和就绪状态，变化则拒绝保存。检索限定不证明模型结论正确，不替代完整评审或专家核验，原解析及历史问答不重写。
