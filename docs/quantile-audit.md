# CSV分位数与四分位距

新复算使用csv-descriptive-audit@2，在全表和每个分组的quantiles中保存method=R-type-7、q1、median、q3和iqr。原有限十进制值过滤、缺失/非法计数、均值、样本标准差、最小/最大和均值容差比较不改。

对有效值的副本排序，n个样本的零基h=(n−1)p；在floor(h)与下一顺序统计量之间线性插值，p分别为0.25/0.5/0.75，IQR=Q3−Q1。定义参考 [R官方quantile文档type7](https://stat.ethz.ch/R-manual/R-devel/library/stats/html/quantile.html)。不运行R、不声称逐位等同R所有边界或支持其全部类型。不同分位数定义可能给出不同结果，比较前需核对方法。

没有有效值时字段为null；一个值时三个分位数等于该值，IQR为0。异号极端值通过有限中点分段插值，避免直接端点相减溢出；IQR超出有限双精度范围时为null并告警。显示最多8位有效数字，JSON保留浮点结果；这些是近似数值计算，不是任意精度。中位数和IQR不自动判断离群值、异常原因、正态性、独立性、显著性或因果，不会删行或替换论文均值比较。

界面分表显示分布位置与离散程度，JSON保存方法与数值。报告面板和导出摘要读取冻结快照，全表及分组均可复查；后续复算不改旧报告。旧@1快照缺少quantiles时显示未记录，不从均值/标准差推算，也不补造字段或修改原JSON。报告旧对象同样保持；CSV原文仍只在请求内处理。
