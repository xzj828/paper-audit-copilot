# 相邻页一键切换与跨页证据边界

## 使用方法

打开 PDF 相邻页对照，选择上一页或下一页，再点“将第 N 页设为当前页”。原对照页成为当前页、原当前页保留为对照页；切换方向随之反转，可反复核对同一对原页，不会自动向后滑到第三页。工作台与文献库预览均支持，手机上的按钮会换行排列。

工作台复用既有原页导航：切换时清除旧引文、文字锚点、视觉区域、搜索词与断词候选状态，再显示目标原页。原先另一页上的相同表头不会继承高亮；需要定位文字时重新搜索并点击该页来源。页面未渲染完成时按钮暂不可用，单页文件及关闭对照时不显示切换按钮。缩放和刷新仍沿用既有阅读行为。

本功能是人工阅读交互，不自动识别续表，也不会合并页文本、原文引文、单元格或模型上下文。两页分别有页码；邻页仍不创建证据框、重复page-ID或来源锚点。

## 开发控制与许可材料

新增三页手写 PDF：第1页 Table A 的首段、第2页明确标注 continued 的续段、第3页独立 Table B。三页均使用 Sample/Measurement 表头，行数据与标题各异。材料由开发者编写用于回归，未作为独立预登记集或真实研究论文；连续/非连续关系是控制作者给定，系统不推断该关系。

实际生产 Worker 检查三页身份和原文，三个同名表头均可按本页偏移定位，任意其他页身份均拒绝；跨页末尾/下一页标题组合在各页搜索中无命中。浏览器真实上传，逐页搜索三次表头，切换1→2→3与手机2↔3，检查旧高亮消失、邻页无框、页码和对照方向正确、刷新重置，完整解析及报告字段保持（本控制未生成评审报告）。

另一项文献库实际上传使用未修改的 Beule 与 Karlovsky（2021）PLOS20页原PDF，CC BY 4.0，原来源与SHA-256见 tests/fixtures/published-pdf/source.json。预览中六次来回切换物理第1/2页，始终只显示两张画布，页码正确且完整解析不变。它验证许可原页阅读流程，不验证真实跨页表格重建。原Table 1第4页与邻页的v16回归另保留复跑。

本轮当前实现指纹和完整检查见 pdf-page-swap-validation.json；原相邻页回归的当前复跑见 pdf-comparison-validation.json。所有自动控制均未调用外部模型，不统计专家准确率、自动续表识别准确率或用户时间收益。
