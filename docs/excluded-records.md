# CSV数值列排除记录

新复算保持csv-descriptive-audit@2，另保存excludedRecords(policy=csv-record-exclusions@1)。字段为valueColumn（数值列零基索引）、limit=20、total、omitted、records及notice；每条记录只含record和kind（missing或invalid）。按源CSV记录顺序保留最先20条，其余只计数，满足total=records.length+omitted。

record从标题之后的第一条数据记录开始计1。CSV带引号字段可含LF/CRLF，内部换行不增加序号，因此这些位置不是文本编辑器或电子表格的物理行号；应在原CSV的记录层核对。清单仅针对所选数值列，不评判其他列质量、异常值原因、显著性或独立性。没有自动删除原表记录、纠错或猜测NA等格式。

分类与描述统计共用同一入口：trim后空白为缺失，原有有限十进制规则拒绝的值为非法，其他值进入原统计算法。数值解析、均值/样本标准差/分位数/容差规则保持，不是新的任意精度实现。清单不保存原始单元格内容，不增加原有分组名称、重复ID示例及可选论文引用的保存范围；这些既有信息仍可能包含用户提供的文字。CSV原文件仍仅在请求内处理。

证据工具与报告共用同一显示组件，列表默认收起，按钮有展开状态和关联区域，可键盘操作；240px内滚动，最多20条。全表无排除与历史未记录分别提示。新JSON直接导出已保存字段，新报告摘要及Markdown/PDF/DOCX附录保留实际清单/未列出数量；后续复算不改变旧报告。旧@1/@2快照没有该字段时不从缺失/非法数量猜测记录位置，不回填或迁移。
