# Report Serif

Static 400/700 instances derived from Noto Serif SC Variable (Adobe, 2017–2023),
renamed Report Serif. Distributed under SIL OFL 1.1; see OFL.txt.
License source: https://github.com/google/fonts/blob/main/ofl/notoserifsc/OFL.txt

The fonts contain GB2312 common Chinese, Latin, Greek, punctuation and math
characters. Other characters use the report's system serif fallback.
They load locally without a font CDN. Regenerate with
`python scripts/build-report-font.py /path/to/NotoSerifSC-VF.ttf` (fonttools/brotli).
