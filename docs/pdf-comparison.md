# PDF 相邻页人工对照

在论文批注阅读区或文献预览中勾选“相邻页对照”，选择上一页或下一页。桌面两列、窄屏上下排列；可滚动查看原比例页面，也可配合现有最大化预览及缩放。首尾页不能选择越界方向，跳页后若原方向越界会切换到唯一可用方向。单页文件不显示开关。

开启后可点“将第 N 页设为当前页”：对照页成为当前页，原当前页保留为对照页，来回切换始终保留所选两页。工作台切换会清除旧文字框、视觉框及原文搜索词，文献预览同步页码并回到顶部；不会把旧页高亮带到相同表头上。关闭或刷新仍重置对照状态。详见 pdf-page-swap.md。

当前页标注为证据定位页，对照页标注为仅查看原页。原始 PDF 各页独立渲染，保留旋转和裁剪；对照页不创建文字框、来源锚点或重复 page-ID。不会把两页当成同一引文，也不会判断表格是否延续、复制表头或重建单元格关系。换行断词搜索仍不跨页。

对照开关默认关闭，刷新和文件版本切换重置。开启期间只显示当前页与一张相邻页；关闭后恢复原来的单页或连续阅读偏好，偏好本身不改写。对照页立即渲染，避免横向滚动区外的懒加载留下空白；连续阅读继续按需加载。渲染尚未完成时不展示旧页画布，邻页失败显示错误及重试。

## 材料与实际验证

新增两项真实上传浏览器流程。开发者手写三页 PDF 预先给定重复文字、旋转裁剪页和矢量空白页：检查第一页/末页方向、前后跳页、旋转比例、立即渲染、当前页第二处引文的原始偏移、邻页不创建位置框、390px上下排列和缩放、刷新重置、修订上传单页文件后隐藏，并核对旧解析快照完全相同。这是工程控制，不是真实研究论文，也不是预登记独立评价集。

另一项上传未修改的 Beule 与 Karlovsky（2021）PLOS 原始20页 PDF（CC BY 4.0，来源与指纹见 tests/fixtures/published-pdf/source.json）。第4页 Table 1 分别与第5、3页对照，当前页搜索位置框保留；关闭后恢复既有连续阅读的16张后续页，完整解析快照相同。该 Table 1 本身未跨页，案例验证原始表格与邻页上下文阅读，不宣称跨页表格重建成功。

实现、测试指纹和本轮完整检查记录见 pdf-comparison-validation.json。旧断词固定材料与许可原文定位复跑，同预期18/18、3/3；仅刷新实际阅读器与CSS实现指纹，旧v15记录保留归档。所有检查均未调用外部模型，不计算专家准确率。
