## 已覆盖场景

1. 匿名空间隔离：另一浏览器身份不能读取、修改、删除项目，也不能读取论文文件或生成报告。
2. 上传：拒绝伪装 PDF，解析真实 PDF 文本与坐标，识别重复内容。
3. DOCX：解析中文段落，保存为独立新版本，保留旧报告。
4. 状态：未确认稿件类型或未启用模型不能启动科学评审；未执行检查不计分；损坏文件解析失败并可重试。
5. 对话：版本范围正确；原文检索有引用；未配置模型时明确说明能力边界。
6. 删除：删除项目记录及磁盘原文件；跨来源写入被拒绝。
7. 证据：8 条演示意见均能对应实际演示片段；伪造引文无法通过引用校验。
8. 快照：修改问题跟踪状态、任务配置或运行结果，不改写已经生成的历史报告。
9. 浏览器：上下条批注、修改建议、确认状态、问 Copilot、引用跳转、原文搜索、报告导出与刷新恢复。
10. 真实全流程：新建 → PDF 上传解析 → canvas 原文渲染 → 解析报告 → DOCX 新版 → 差异比较 → 刷新 → 删除。
11. 手机：390×844 下没有横向页面溢出，论文/对话切换可用，弹窗可通过 Escape 关闭。
