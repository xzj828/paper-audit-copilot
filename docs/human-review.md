# 冻结报告的人工复核与分歧清单

本功能准备复核材料、校验两份记录并保留分歧；没有取得真实领域专家标注，不认证复核者身份，不给出专家准确率或全文问题召回率。现有calibration.mjs仍用于另外准备的专家问题集，不能把本功能的“选择一致”当作专业结论正确。

## 使用

在所选论文版本的“评审报告”打开“人工复核材料与分歧”，下载人工复核材料和空白记录模板。两名复核者分别对照原文件与图表阅读材料，各自填写模板，不要让模型产生标注后冒充独立人工记录。原文件不会由此工具自动发送给其他人。

填写reviewer.id为本人代号；role如实选择independent_human（声明独立人工）、developer（开发者）或model_assisted（模型辅助）。recordedAt填写含时区的实际ISO复核时间，例如2026-10-09T12:00:00+08:00。日期须存在，小时为00–23；不会把2月30日或24:00自动换算后接受。支持闰年、Z或数值时区以及1–3位小数秒，合法写法原样保留。时间格式正确不证明复核实际发生。四项逐条选择：accuracy（问题准确性）、evidenceSupport（证据支持）及actionability（建议可执行性）为yes/no/unable；severity为none/minor/major/critical/unable。默认null是未填写，不是“无问题”；否定或无法判断必须写note说明理由。

分别导入两份完成的JSON记录，点击比对。完整材料身份必须一致，所有问题恰好标注一次；缺失、额外、重复问题、错误材料指纹、相同代号、未填选择或缺少理由都会拒绝。结果按冻结报告原顺序保留全部选择及双方说明，可下载完整JSON。切换报告或版本会清空当前导入文件和比对结果；刷新后需要重新导入，下载文件是保存本次比对的方式。

三类按问题互斥计数：四项明确选择相同为“选择一致”；任一不同为“分歧，需要裁决”；全部选择相同且至少一项unable为“双方无法判断，材料不足”。相同选择不证明真实正确，分歧与材料不足不会自动关闭问题、改变严重性或修改历史报告。原报告没有问题时显示0条，不能解释为论文没有缺陷。

本地复现比对：npm run compare:human-review -- 复核材料.json 记录A.json 记录B.json 结果.json。CLI和服务端使用同一验证及比较函数；本地指纹校验只说明内容未变，不能认证文件来自本系统、两名真实不同人员或某个专家机构。

## 身份与证据

human-review-packet@1绑定所选版本ID、解析ID、文件SHA-256、冻结报告ID及生成时间。若历史报告缺少解析身份，或报告与版本、解析、已记录源哈希不一致，则拒绝导出，不能借当前原文补造旧报告证据。API要求显式版本并检查工作空间，不回退到活动版本。

问题取自报告自身冻结findings，当前可变批注和对话不进入材料。每处文本引文按exact-occurrence规则核对原区块、页和UTF-16偏移；有效引文附前后各150字符以内的上下文，引用仍逐字保留。旧歧义、错偏移、错页、缺源分别标记，不猜位置。视觉证据标为需要核对原文件，材料不包含完整页图；有限文本片段不代表全文或图表已经检查。

隐藏结构化模型配置、评分、系统建议等级、原问题严重性及模型verification字段。原问题文字中仍可能含有判断提示，所以这是隐藏指定字段的复核包，不是完整盲评设计。材料与问题编号的指纹采用规范化JSON SHA-256，稳定于同一冻结材料，不是数字签名。

完整材料最多200条问题、每条20处证据、总JSON正文2 MiB；超限拒绝，不静默截断问题或引文。浏览器每份记录256 KiB以内，HTTP比对请求1 MiB；大记录可在本地命令运行，问题数与字段校验仍保留。比对端点只计算返回结果，不调用模型、不修改问题或报告。

## 已验证的软件边界

实现前真实提交b2ce3de登记10项开发者合成控制，SHA-256 14475e48a1221c2119ab5a75e7967948ed928303f8b4d8b6aaf769dc3f07b3cc，源与预期未改；10/10控制通过，包括分歧、双方无法判断、错指纹、重复代号、漏项、额外问题、重复问题、未完成和篡改材料。全部名称与标注都是软件控制，不是两名真实专家的评价。npm run evaluate:human-review -- --output 指定目录保存全部预期、实际结果、错误与实现指纹，不联网、不调用模型。

新增Node验证冻结与字段清单、原文切片、旧身份和容量拒绝、各类不可定位证据、零问题不造指标、离线CLI与保留全部说明。API检查跨工作空间、显式版本、错误材料、专用请求体限制和只读快照。浏览器实际上传手写PDF后，仅在独立E2E数据库存入标明开发者控制的冻结报告，再验证真实下载、模板、导入、比对、390px分歧查看、完整JSON下载及切换旧报告清空状态。它不声称实际模型或领域专家产生了这些意见。

当前还需要真实独立领域复核者、许可明确的保留样本、完整漏检问题集和分歧裁决记录，才能评估专业质量；本工具不会用自编控制替代这些外部条件。

## v36 比对结果筛选

可选择全部问题、需要裁决、双方无法判断或选择一致，当前显示数与全部问题数分开列出。具体分歧行同时有文字、加粗与边线提示；筛选仅影响浏览，不裁决问题、不更改总计。下载始终保留完整结果及双方说明。重新导入记录后旧结果失效，新比对默认回到全部问题；报告切换继续清空当前记录。空清单不表示全文无缺陷。详见[筛选与验证](human-review-triage.md)。
