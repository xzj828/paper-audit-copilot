# 文献库与模板页改版

依据用户确认的三张参考图，调整文献库、模板与规范列表及版本详情。现有文献、集合、配置版本和评审记录继续使用原 API。

- 文献库：默认紧凑列表，保留真实首页缩略图、文件名、格式、大小、集合、版本、解析状态和活动时间。仍可切换网格，已有视图偏好继续生效。
- PDF 首页通过已有 PDF.js 按需渲染；预览进入可视区后加载，组件销毁时取消请求、释放 PDF。最多缓存 48 份预览，仅保留在内存中。DOCX 展示实际解析正文节选，明确标注，最多保留 2200 字符。原始文档缺失时显示预览不可用，解析失败时保留重试入口。
- 模板页：默认展示全部有效标准及报告模板，以蓝、绿、灰、紫封面区分证据核查、方法统计、基础检查和报告结构。名称采用精简展示名，详情和保存记录保留原配置名称与版本身份。
- 删除整排筛选和常用视图；搜索框缩至 332 × 40 px，排序与批量选择收入“更多”浮层，展开不推动列表。文献回收站移入该菜单，侧栏移除空集合提示及底部冗余说明。归档模板可在“已归档”中恢复。
- 版本详情采用双栏弹窗，左侧简短目录切换检查项目，右侧展示评分内容；手机端目录横向滚动。明确写出完整 4–0 级评分的原始规则拆为五行；完整原文可展开查看。门槛项、非评分项及自由格式规则原样展示，避免推测评分。复制版本保留完整原始数据。
- 本轮同时保留共享工作区中独立新增的模板编辑器及其创建入口。
- 左侧导航统一间距；新建项目、最近项目、研究空间、侧栏收起及设置入口继续可用。键盘焦点、触屏操作和三种主题保持支持。

## 验证

`npm run build` 通过 TypeScript 和 Vite 构建。

相关浏览器回归：

```sh
npx playwright test tests/e2e/catalog-compact.spec.js tests/e2e/catalog.spec.js tests/e2e/management.spec.js tests/e2e/interaction-refinement.spec.js tests/e2e/workspace.spec.js
```

新增测试验证排序菜单不引起布局位移、原始规则保真、独立复制、真实缩略图、回收站恢复及手机端三种主题。规则展示函数的两项单元测试通过。全量单元测试 290 项中 289 项通过；剩余离线缓存测试因 Windows 创建符号链接权限报 EPERM。

最终浏览器验证使用独立端口及数据目录，以避开共享工作区中的另一轮测试。29 项回归首次通过 26 项；修正刷新后重复点击导航的旧测试并复查后，文献库及报告快照测试通过。本次新增 5 项全部通过，累计 28 项通过；已有工作台的聊天区滚轮测试仍失败（scrollTop 保持 0），尚未在本轮页面改版中解决。
